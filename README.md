A program that writes the GPS's own one-line excuse for sending the driver down the wrong road — smug, defensive, blaming the map, and landing the driver at a cul-de-sac wedding instead. It writes exactly one line of plain text (147 characters) to `/output/entry.txt` for the [make.fun bounty](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9).

## Run

```sh
python3 main.py
```

For local testing, set `OUTPUT_DIR` to an isolated directory (the program then writes `<OUTPUT_DIR>/entry.txt` instead of `/output/entry.txt`):

```sh
OUTPUT_DIR=/tmp/out-gps-alven python3 main.py
```

## The line

> I didn't get you lost, I got you invited: the map called this cul-de-sac a shortcut, and the bride just thanked me for bringing you to her wedding.
